# Coaching Ventas

Aplicación para gestión de coaching de ventas con Google Sheets como base de datos.

## Características

- 📝 Registro de coaching
- 📊 Dashboard con métricas
- 🎯 Categorías a mejorar
- 📂 Historial de coaching
- ⚙️ Gestión de maestros
- 📧 Notificaciones por email automáticas

## Instalación

```bash
pip install -r requirements.txt
streamlit run app.py
